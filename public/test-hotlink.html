🔒 Hotlink Protection Test

✅ What's Protected:

  • All image files: .jpg, .jpeg, .png, .gif, .bmp, .webp, .svg, .ico
  • Images can only be accessed from eureka-performa.com
  • Direct access (typing URL in browser) is allowed
  • External websites CANNOT embed your images

🧪 How to Test:

  1. Test 1 - Direct Access (Should Work):
    Copy any image URL from your site and paste it directly in browser address bar
    Example: https://eureka-performa.com/storage/quest-locations/image.jpg
    ✓ Image should load

  2. Test 2 - Same Domain (Should Work):
    Images displayed on your own website pages
    ✓ All images should display normally

  3. Test 3 - External Hotlinking (Should Fail):
    Create a test HTML file on another domain with:
    <img src="https://eureka-performa.com/storage/quest-locations/image.jpg">
    ✗ Image should return 403 Forbidden
📋 Note: If you need to allow specific external domains (like a mobile app or partner site), you can modify the .htaccess file to whitelist them.
