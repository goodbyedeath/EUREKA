## 🎯 Pengenalan Aplikasi

### Apa itu EUREKA?
EUREKA adalah aplikasi web progresif (PWA) yang menggabungkan sistem kuis interaktif dengan quest berbasis lokasi. Aplikasi ini dirancang untuk pembelajaran berbasis tim yang menyenangkan dan engaging, cocok untuk:
- Program pelatihan korporat
- Kegiatan pembelajaran institusi pendidikan
- Team building activities
- Event gamifikasi

### Fitur Utama
- ✅ **Sistem Tim**: Semua aktivitas berbasis tim dengan sistem poin kolektif
- ✅ **Kuis Interaktif**: Akses melalui QR code dengan berbagai jenis pertanyaan
- ✅ **Quest Lokasi**: Check-in di lokasi fisik menggunakan GPS
- ✅ **PWA Mobile**: Pengalaman seperti aplikasi mobile
- ✅ **Multibahasa**: Bahasa Indonesia dan Inggris
- ✅ **Real-time**: Update progress secara langsung

## 🚀 Memulai Penggunaan

### Langkah 1: Akses Aplikasi
1. Buka browser di perangkat Anda
2. Masukkan URL aplikasi EUREKA
3. Aplikasi akan otomatis menyesuaikan dengan perangkat mobile

### Langkah 2: Registrasi/Login
1. **Registrasi Baru:**
   - Klik tombol "Daftar"
   - Isi nama lengkap
   - Masukkan email valid
   - Buat password yang kuat (min. 8 karakter)
   - Konfirmasi password
   - Klik "Daftar"

2. **Login:**
   - Masukkan email dan password
   - Klik "Masuk"

### Langkah 3: Verifikasi Email
- Cek email untuk link verifikasi
- Klik link untuk mengaktifkan akun
- Kembali ke aplikasi untuk melanjutkan

## 👥 Panduan untuk Pengguna Biasa

### A. Setup Awal

#### 1. Registrasi Tim
**Wajib dilakukan sebelum menggunakan fitur utama!**

1. Setelah login, Anda akan diarahkan ke halaman registrasi tim
2. **Pilihan A - Bergabung dengan Tim Existing:**
   - Pilih "Bergabung dengan Tim"
   - Masukkan kode tim yang diberikan leader
   - Klik "Bergabung"

3. **Pilihan B - Membuat Tim Baru:**
   - Pilih "Buat Tim Baru"
   - Masukkan nama tim (unik)
   - Anda otomatis menjadi leader tim
   - Bagikan kode tim ke anggota lain

#### 2. Mengatur Profil
1. Klik ikon profil di pojok kanan atas
2. Lengkapi informasi profil
3. Upload foto profil (opsional)
4. Simpan perubahan

### B. Dashboard Utama

#### Navigasi Dashboard
Dashboard terbagi dalam beberapa tab:
- **📊 Statistik**: Ringkasan progress dan poin tim
- **🎯 Quest**: Daftar quest locations dan games
- **📝 Kuis**: Riwayat dan kuis yang tersedia
- **👥 Tim**: Manajemen anggota tim

#### Memahami Statistik
- **Total Poin Tim**: Poin kolektif yang dikumpulkan tim
- **Kuis Selesai**: Jumlah kuis yang telah diselesaikan
- **Lokasi Dikunjungi**: Quest locations yang sudah di-check-in
- **Ranking**: Posisi tim dibandingkan tim lain

### C. Mengikuti Kuis

#### 1. Cara Mengakses Kuis

**Metode A - Scan QR Code:**
1. Tap tombol "Scan QR" pada dashboard
2. Izinkan akses kamera
3. Arahkan kamera ke QR code kuis
4. Kuis akan terbuka otomatis

**Metode B - Browse Kuis Tersedia:**
1. Masuk ke tab "Kuis"
2. Pilih kuis dari daftar yang tersedia
3. Klik "Mulai Kuis"

#### 2. Mengerjakan Kuis

1. **Persiapan:**
   - Pastikan koneksi internet stabil
   - Baca instruksi dengan teliti
   - Perhatikan batas waktu (jika ada)

2. **Selama Kuis:**
   - Jawab pertanyaan satu per satu
   - Klik "Selanjutnya" untuk lanjut
   - Timer akan berjalan otomatis
   - Progress tersimpan otomatis

3. **Jenis Pertanyaan:**
   - **Pilihan Ganda**: Pilih satu jawaban yang benar
   - **Benar/Salah**: Pilih True atau False
   - **Isian Singkat**: Ketik jawaban langsung
   - **Gambar**: Pertanyaan dengan visual

4. **Menyelesaikan Kuis:**
   - Review jawaban sebelum submit
   - Klik "Selesaikan Kuis"
   - Lihat hasil dan poin yang diperoleh

#### 3. Fitur Khusus Kuis

**Resume Kuis:**
- Jika terputus, kuis dapat dilanjutkan
- Progress otomatis tersimpan
- Waktu akan berlanjut dari titik terakhir

**Multiple Attempts:**
- Beberapa kuis mengizinkan percobaan ulang
- Nilai terbaik yang akan dihitung
- Cek batas maksimal percobaan

### D. Quest Locations

#### 1. Melihat Quest Locations
1. Masuk ke tab "Quest"
2. Aktifkan GPS/lokasi di perangkat
3. Lihat daftar lokasi terdekat
4. Perhatikan jarak ke setiap lokasi

#### 2. Check-in ke Lokasi

1. **Persiapan:**
   - Pastikan GPS aktif
   - Koneksi internet tersedia
   - Datang ke lokasi fisik yang ditentukan

2. **Proses Check-in:**
   - Pilih lokasi yang ingin dikunjungi
   - Navigasi ke lokasi tersebut
   - Ketika sudah dekat (dalam radius), tombol check-in akan aktif
   - Klik "Check In"
   - Poin otomatis ditambahkan ke tim

3. **Tips Check-in:**
   - Pastikan berada dalam radius yang ditentukan
   - Jika tombol tidak aktif, coba refresh lokasi
   - Beberapa lokasi mungkin memerlukan foto sebagai bukti

### E. Game Dashboard

#### 1. Mengakses Games
1. Dari dashboard utama, pilih "Games"
2. Browse games yang tersedia
3. Klik game yang ingin dimainkan

#### 2. Bermain Game Lokasi
1. **Persiapan:**
   - Pastikan tim sudah terdaftar
   - GPS aktif untuk tracking lokasi
   - Koneksi internet stabil

2. **Gameplay:**
   - Ikuti instruksi game
   - Kunjungi koordinat yang ditentukan
   - Selesaikan challenge di setiap titik
   - Kumpulkan poin untuk tim

3. **Assessment Game:**
   - Setelah selesai, isi form penilaian
   - Berikan feedback tentang game
   - Poin tambahan mungkin diberikan

### F. Manajemen Tim

#### 1. Melihat Anggota Tim
1. Masuk ke tab "Tim"
2. Lihat daftar semua anggota
3. Cek status dan kontribusi masing-masing

#### 2. Fitur untuk Team Leader

**Mengelola Anggota:**
- Tambah anggota baru dengan kode undangan
- Edit informasi anggota
- Lihat statistik kontribusi individual
- Set role anggota (jika diperlukan)

**Monitoring Progress:**
- Track progress tim secara keseluruhan
- Lihat history aktivitas
- Export laporan progress

## 👨‍💼 Panduan untuk Admin

### C. Manajemen Tim

#### 1. Membuat Tim Baru
1. Klik "Buat Tim Baru"
2. Isi informasi tim:
   - Nama tim (harus unik)

#### 2. Mengelola Tim Existing
- **Edit Tim**: Ubah informasi tim
- **Manage Members**: Kelola anggota tim
- **View Statistics**: Lihat statistik tim
- **Export Data**: Export data tim ke Excel/CSV

#### 3. Monitoring Tim
1. Dashboard menampilkan:
   - Total tim aktif
   - Ranking tim berdasarkan poin
   - Aktivitas tim terbaru
   - Statistik partisipasi

### D. Manajemen Kuis

#### 1. Membuat Questionnaire Baru
1. Masuk ke "Quiz Management"
2. Klik "Buat Questionnaire"
3. Isi detail questionnaire:
   - Judul questionnaire
   - Deskripsi
   - Upload foto (opsional)
   - Set passing score
   - Tentukan batas waktu
   - Atur jumlah percobaan maksimal

#### 2. Menambah Pertanyaan
1. Pilih questionnaire yang sudah dibuat
2. Klik "Tambah Pertanyaan"
3. Pilih jenis pertanyaan:
   - **Multiple Choice**: Pilihan ganda
   - **True/False**: Benar/salah
   - **Short Answer**: Jawaban singkat
   - **Fun Game**: Pertanyaan game interaktif

4. Isi detail pertanyaan:
   - Teks pertanyaan
   - Upload gambar (jika diperlukan)
   - Set jawaban yang benar
   - Tentukan poin untuk pertanyaan
   - Tambah penjelasan (opsional)

#### 3. Generate QR Code
1. Setelah questionnaire selesai
2. Klik "Generate QR Code"
3. Download atau print QR code
4. Distribusikan ke peserta

#### 4. Monitoring Quiz
- Lihat statistik pengerjaan
- Monitor tingkat keberhasilan
- Analisis jawaban yang sering salah
- Export hasil ke Excel

### E. Manajemen Lokasi

#### 1. Membuat Quest Location
1. Masuk ke "Location Management"
2. Klik "Tambah Lokasi"
3. Isi informasi lokasi:
   - Nama lokasi
   - Deskripsi
   - Koordinat GPS (lat, lng)
   - Radius check-in (meter)
   - Poin reward
   - Upload foto lokasi

#### 2. Mengelola Lokasi Existing
- **Edit Lokasi**: Ubah informasi
- **Update Koordinat**: Sesuaikan posisi GPS
- **Set Status**: Aktif/nonaktif
- **View Analytics**: Lihat statistik kunjungan

#### 3. Import/Export Lokasi
- Import bulk lokasi via CSV
- Export data lokasi
- Template CSV tersedia

### F. Manajemen Game

#### 1. Membuat Game Baru
1. Masuk ke "Game Management"
2. Klik "Buat Game"
3. Setup game:
   - Nama dan deskripsi game
   - Pilih lokasi game
   - Set koordinat dan radius
   - Upload gambar/map
   - Tentukan poin reward

#### 2. Game Assessment
- Setup form penilaian post-game
- Konfigurasi pertanyaan feedback
- Set poin tambahan berdasarkan assessment

### G. Hero Slides Management

#### 1. Mengelola Banner Utama
1. Masuk ke "Hero Slides"
2. Upload gambar banner
3. Set teks overlay
4. Atur urutan tampilan
5. Set status aktif/nonaktif

#### 2. Responsive Design
- Upload berbagai ukuran gambar
- Preview untuk desktop dan mobile
- Optimasi loading time

## 🔧 Pemecahan Masalah

### Masalah Umum

#### 1. Tidak Bisa Login
**Gejala**: Error saat login atau redirect berulang

**Solusi**:
1. Clear browser cache dan cookies
2. Coba browser berbeda
3. Reset password jika perlu
4. Contact admin jika masih bermasalah

#### 2. GPS Tidak Berfungsi
**Gejala**: Lokasi tidak terdeteksi atau tidak akurat

**Solusi**:
1. Enable location services di browser
2. Allow location access untuk website
3. Coba refresh halaman
4. Restart browser atau device
5. Cek setting privacy browser

#### 3. QR Code Tidak Terbaca
**Gejala**: Scanner tidak mengenali QR code

**Solusi**:
1. Pastikan kamera fokus dengan baik
2. Coba dari jarak berbeda
3. Pastikan lighting cukup
4. Clean kamera lens
5. Coba browser berbeda

#### 4. Kuis Tidak Tersimpan
**Gejala**: Progress hilang saat reload

**Solusi**:
1. Pastikan koneksi internet stabil
2. Jangan close tab saat mengerjakan
3. Enable cookies di browser
4. Coba mode incognito untuk test

### Masalah Teknis Lanjutan

#### 1. Performance Issues
**Gejala**: Aplikasi lambat atau sering hang

**Solusi**:
1. Close tab browser yang tidak perlu
2. Clear storage data
3. Update browser ke versi terbaru
4. Restart browser
5. Check available storage space

#### 2. PWA Installation Gagal
**Gejala**: Opsi "Add to Home Screen" tidak muncul

**Solusi**:
1. Pastikan menggunakan HTTPS
2. Cek browser compatibility
3. Clear service worker cache
4. Coba dari browser mode normal (bukan incognito)

#### 3. Sync Issues
**Gejala**: Data tidak ter-update atau konflik data

**Solusi**:
1. Force refresh halaman (Ctrl+F5)
2. Logout dan login kembali
3. Clear application data
4. Report ke admin jika persistent
